# Weather EDA Dashboard

GitHub Pages friendly dashboard build.

Upload/commit all files in this folder to your GitHub repository:

- `index.html`
- `assets/styles.css`
- `assets/dashboard-app.js`
- `assets/dashboard-data.js`

Why this version works on GitHub:

- `index.html` is small.
- Plotly loads from CDN.
- Data and app logic are split into separate files.
- The large single-file HTML version is not needed for GitHub Pages.
